# Whack-a-mole
Whack-a-Mole is a simple and interactive browser-based game built using HTML, CSS, and JavaScript. The game features a 3×3 grid of holes where a mole randomly appears. The player's objective is to click (whack) the mole as quickly as possible before it disappears.
Overview

Whack-a-Mole is a browser-based interactive game developed using HTML, CSS, and JavaScript. The game presents a 3×3 grid where a mole randomly appears in different holes. The player must click on the mole to score points before it disappears.
The objective is to achieve the highest number of successful hits within the given time limit while minimizing missed clicks.
Features
Random mole appearance in a 3×3 grid
Animated mole popping effect
Hit counter
Miss counter
High score system (stored using browser localStorage)
30-second countdown timer
Start, Pause, and Restart functionality
Responsive and simple user interface
Technologies Used
HTML – Structure and layout
CSS – Styling and animations
JavaScript – Game logic and interactivity
How to Run the Project
Download or clone the repository.
Open the project folder.
Double-click the index.html file
OR
Open it using a browser (Chrome, Edge, Firefox, etc.).
No additional installations or dependencies are required.Game Controls
Start – Begins the game.
Pause – Temporarily stops the timer and mole movement.
Restart – Resets the game and starts again.
