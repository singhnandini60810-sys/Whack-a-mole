# 🐹 Whack-A-Mole Game

An interactive browser game built using HTML, CSS and JavaScript.

## Features

- Random mole spawning
- 3×3 interactive grid
- Animated mole movement
- Score tracking
- Miss counter
- High score saved with LocalStorage
- 30 second timer
- Start / Pause / Restart controls
- Dynamic difficulty
- Responsive design
- Hammer animation

## Tech Stack

HTML5  
CSS3  
JavaScript
